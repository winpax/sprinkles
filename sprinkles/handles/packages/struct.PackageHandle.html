Get the package’s name

§Safety

This field is manually set in the remote manifest, and by default is uninitialized. This may cause undefined behavior.

Use Manifest::name_opt or, to ensure that this function returns properly, use the CreateManifest trait to set the name, or create the manifest, rather than other methods that might fail to set the name.
